# archive

这里存放制作页面时使用过的原始素材和一次性脚本。**网站运行不依赖这个目录**，保留它们只是为了日后修订讲义时有据可查。

| 目录 | 内容 |
|------|------|
| `biochemistry/` | 生物化学讲义（`/chemistry/biochemistry.html`）的原始资料：各章正文（蛋白质、核酸、糖类、脂类、糖代谢、酶化学）、章节习题库（`_sec_*.txt`）、习题数据（`_pq2.json`、`_ex_ids.txt`），以及生成页面时用到的页头页尾模板和中间产物 |
| `scripts/` | 早期生成讲义和旧版科研孵化页面的脚本。对应页面已经重写，这些脚本不再维护 |
