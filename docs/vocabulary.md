# 雅思单词记录本

页面入口 `/ielts`，导航产品矩阵、移动端菜单、页脚和多维知识库均可进入。
直接复用 `head/nav/footer/tail` 公共片段与 `cyjy.css`，页面附加 CSS 仅负责布局。
单词清单不读写 localStorage；主题偏好仍由全站公共脚本管理。

## 数据维护与发布

共享清单为仓库 `content/ielts-words.json`，初始为空，不包含虚构的个人记录。
将单词添加到此文件并提交至 GitHub `main`，已部署的网站会检查新内容。
也可以将原 HTML「导出 JSON 备份」得到的整个对象直接作为这个文件的内容（也兼容纯数组）。
原 HTML 内嵌的查词词典不是个人清单，不作为雅思记录导入。

```json
{
  "words": [
    {
      "word": "resilient",
      "phonetic": "/rɪˈzɪliənt/",
      "zh": "adj. 有韧性的；适应力强的",
      "createdAt": 1791244800000
    }
  ]
}
```

上述仅为格式示例。`word` 必须为非空字符串；`phonetic`、`zh` 可省略。
支持原记录本的 `zhGroups: [{"pos": "adjective", "text": "有韧性的"}]`。
`createdAt` 为 Unix 毫秒时间戳，缺失或无效时不显示日期。
按最新排序时无日期记录放在后面，同日期保留文件顺序。
页面上添加或删除单词后，服务端会把整个清单按单词字母 A–Z（大小写不敏感）重写回文件，
因此仓库里的 JSON 与导出结果始终是有序的；`createdAt` 保留，「最新/最早记录」排序照常可用。
文件最大 2 MB、最多 10000 条；格式错误会拒绝整个新版本并保留旧数据。
导出文件中其他字段不会在页面执行；释义和单词通过 textContent 渲染。

首次上线需将本次代码和数据文件一同合并、部署。在数据文件尚未发布时，
页面会明确提示同步不可用，不会把本地示例或空清单宣称为远程同步成功。
新记录通过 GitHub 修改；登录用户也可以直接在页面上添加（见下）。
当前范围是共享清单的在线浏览与登录用户添加，未提供个人账户私有词库。

## 在页面上添加单词

- 工具栏的「添加单词」展开表单：填写单词（必填）、音标、中文释义后保存。
- 必须登录：未登录时按钮显示「登录后添加」，点击会跳转到登录页，登录后回到本页。
- 保存后由服务端追加 `createdAt`（当前时间毫秒）并写回仓库，提交信息带 `[skip render]`，
  不会触发 Render 重新部署；同时立即更新内存快照，页面马上显示新单词。
- 单词大小写不敏感地去重，重复时返回 409；同一账号每分钟最多添加 10 次。
- 写入依赖 `CYJY_GITHUB_TOKEN`（线上已配置）。未配置令牌的只读实例上添加会返回错误。

## 在页面上删除单词

- 登录以后，每张单词卡片右上角出现「删除」；第一次点击变成「确认删除？」，再点一次才真正删除，
  4 秒无操作自动恢复，避免误删。
- `DELETE /api/v1/vocabulary`，请求体 `{"word": "..."}`，同样需要登录，大小写不敏感匹配。
- 删除后服务端把剩余清单按 A–Z 重写回仓库，提交信息为 `vocab: 删除单词 xxx（用户名）` 且带 `[skip render]`；
  同时立即更新内存快照，页面马上移除该单词。
- 单词不存在返回 404；同一账号添加和删除合计每分钟最多 10 次。
- 与添加一样，任何登录用户都可以删除共享清单中的单词（数据不记录添加人），需要更细的权限时再单独加。
- 仍不支持在线编辑释义；改内容请先删除再重新添加，或直接改仓库 JSON。

## 导出 Word

- 工具栏「导出 Word」下载 `ielts-words-YYYYMMDD.docx`：一列英文、一列中文，音标排在英文单元格的第二行（灰色小字）。
- 导出内容与屏幕上一致：遵循当前的排序方式和搜索关键词，搜索为空时导出全部。
  请求为 `GET /api/v1/vocabulary/export?sort=az|za|newest|oldest&q=关键词&phonetic=true|false`。
- 不需要登录；数据不可用时返回 503。
- 文档由 `docx_export.py` 用标准库（zipfile + 手写 OOXML）生成，**项目不新增任何依赖**。

## 同步策略

- `GET /api/v1/vocabulary` 从固定 GitHub 仓库读取公开 JSON，不需要浏览器令牌。
- `CYJY_VOCAB_BRANCH` / `CYJY_VOCAB_PATH` 可指定分支与相对文件路径。
- 页面首次打开、恢复可见、每隔 60 秒和点击「同步更新」时请求同源接口。
- 服务端 60 秒缓存与 ETag 条件请求合并并发访问，失败同样限频；手动同步也遵循此限制。
- GitHub 自身 CDN 可能导致额外传播延迟，不承诺即时强一致。
- 同步失败时保留本次服务运行中最后一次成功数据，并明确标记旧数据；
  首次同步失败返回 503，前端显示错误与重试入口。
- 成功读取空数组是正常空清单，会清除之前的数据。
- 浏览器不持久化词库，服务器内存快照在重启后重新从 GitHub 获取。
